# Documentação do GeoQuest

Atualizada em 2 de novembro de 2026. Aplicação publicada em
[geoquest-raibrs.vercel.app](https://geoquest-raibrs.vercel.app/), com PostgreSQL no Neon.
O serviço antigo do Render foi excluído.

| Documento | Quando consultar |
|---|---|
| [DEPLOYMENT.md](DEPLOYMENT.md) | Publicar na Vercel, configurar variáveis, banco, callbacks e executar testes. |
| [VERCEL_MIGRATION.md](VERCEL_MIGRATION.md) | Entender a migração concluída, o estado compartilhado e as verificações registradas. |
| [DOCKER_TROUBLESHOOTING.md](DOCKER_TROUBLESHOOTING.md) | Consultar o diagnóstico e a recuperação da falha do Docker Desktop. |
| [SPRING_OAUTH_REVIEW.md](SPRING_OAUTH_REVIEW.md) | Entender a autenticação Spring, sessões, CSRF e o histórico da migração HTTP. |
| [REDESIGN.md](REDESIGN.md) | Entender a organização da interface, navegação, estilos e preferência de idioma. |
| [RESPONSIVE_QA.md](RESPONSIVE_QA.md) | Consultar os testes de navegador, larguras verificadas e limitações em dispositivos físicos. |

O [README principal](../README.md) apresenta o jogo e a execução local. Os relatórios preservam
resultados históricos com suas datas; consulte o guia de publicação para a configuração atual.
Valores de credenciais não devem ser incluídos nestes arquivos.
